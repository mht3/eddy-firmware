# Sub-GHz Signal Meter

The Eddy app measures received signal strength at 433.92 MHz. A saved observation contains the frequency and the measured level in dBm.

Sub-GHz transmission in the radio drivers requires a supported frequency inside the factory region. Worldwide and unrecognized hardware stays receive-only. A region file on the device cannot expand these permissions. For regional restrictions and supported frequencies, see the [Flipper Zero documentation](https://docs.flipper.net/zero/sub-ghz/frequencies).
