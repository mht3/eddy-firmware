EDDY WIKI

Project origins.

Hi! I’m a PhD student in the computer science department at UC San Diego. Eddy is a custom firmware for the Flipper Zero. I thought eddy would be a fitting name in order to keep the dolphin and ocean theme going :)

Eddy is a fork of Momentum, the Open-Source project from Next-Flip. I really loved what they did to make the user interface more clean and accessible. After using that firmware for a while, I decided to make my own sleek design and interface in hopes to make the device feel more modern and accessible to people! My code is open source and free to use by anyone.

If you enjoy using my Eddy Flipper Zero firmware, you can support me with a donation on Ko-fi. If something goes wrong, report a bug on GitHub. I’d also love to hear your suggestions for new apps and features.
